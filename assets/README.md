# 그림과 소리 목록

여기에 넣은 파일마다 아래 표에 한 줄씩 적는다. Claude Code는 이 표를 보고 그림을 화면에 넣는다.

## 넣는 곳

| 폴더 | 넣는 것 |
|---|---|
| `img/` | 화면에 실제로 들어가는 조각 그림(구름, 물방울, 버스, 아이콘 등) |
| `ui/` | 완성 화면 시안. 배치와 색을 맞추는 참고용 |
| `sound/` | 효과음(mp3) |

## 지킬 것

- 파일 이름은 영어 소문자, 숫자, 밑줄만. 예: `cloud_small.png`, `icon_water.png`, `bg_home.png`
- 조각 그림은 배경이 투명한 PNG 또는 SVG
- 긴 쪽 1000px 이하, 파일당 300KB 이하
- 리니·워니 공식 그림은 사용 허락을 확인한 뒤에 넣는다(저장소가 공개다)
